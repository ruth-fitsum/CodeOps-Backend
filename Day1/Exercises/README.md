# 1. What is a server?

## A server is a program that waits for a request from other programs and response to them. It's like a waiter in a resturant that accepts request from a a customer , sends the requests to the kitchen which then sends the food back to the customer . Similarly, a server provide information , save data or perform actions depending on the request it recieves . It also keeps running so it can accepts requests whenever it's needed . If it stops that would be a failurity.
